# ياسر — نظام الحياة (تطبيق PWA)

تطبيق ويب قابل للتثبيت على الجوال، يشتغل بدون نت، ويحفظ بياناتك على جهازك.
مصمّم خصيصاً للجالكسي فولد: عمود واحد على الشاشة الضيّقة، وعمودين تلقائياً على الشاشة الداخلية المفتوحة.

## النشر على GitHub Pages (٥ خطوات)

1. أنشئ مستودعاً جديداً **Public** (مثلاً باسم `hayati`).
2. ارفع كل هذه الملفات في **جذر** المستودع (مو داخل مجلد):
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-maskable-512.png`
3. من المستودع: **Settings → Pages**.
4. تحت **Source** اختر: **Deploy from a branch** → الفرع `main` → المجلد `/ (root)` → **Save**.
5. انتظر دقيقة، بيظهر رابط مثل: `https://اسمك.github.io/hayati/`

## التثبيت على الجوال

- افتح الرابط من متصفح **Chrome** على الفولد.
- إمّا اضغط زر **«تثبيت ⤓»** داخل التطبيق (أعلى الشاشة)، أو من قائمة المتصفح **«تثبيت التطبيق / Add to Home screen»**.
- بيظهر كأيقونة على الشاشة الرئيسية، ويفتح بملء الشاشة بدون شريط المتصفح.

## ملاحظات

- **بدون نت:** بعد أول فتح، يشتغل حتى بدون إنترنت.
- **التحديث:** لو عدّلت الملفات ورفعتها، غيّر رقم النسخة في `service-worker.js` من `hayati-v1` إلى `hayati-v2` عشان تنزل النسخة الجديدة.
- **نسخة احتياطية:** استخدم زر «نسخة احتياطية ⬇» لحفظ بياناتك كملف JSON، و«استعادة ⬆» لإرجاعها (مفيد عند تغيير الجوال).
- **الشاشة المفتوحة:** لما تفتح الفولد، الأقسام تتوزّع تلقائياً على عمودين.
